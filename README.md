# AI Agent Lab

A hands-on project for learning production-ready AI agent architecture.

## Technology Stack
- Python
- LangGraph
- Ollama (local LLM)
- Model Context Protocol (MCP)
- FastAPI
- PostgreSQL
- DeepSeek API (future)

## Project Roadmap
1. Single-agent architecture with three MCP servers
2. Supervisor-worker multi-agent architecture
3. Parallel agent execution
4. Persistent workflow state and checkpointing
5. Timeout, retry, and failure recovery
6. Observability and evaluation
7. DeepSeek API integration
